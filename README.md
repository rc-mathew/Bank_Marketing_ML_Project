\# Bank Marketing ML Project



An end-to-end machine learning project for predicting whether a bank

customer is likely to subscribe to a term deposit.



\## Project Status



🚧 Under active development



\## Objective



Build a production-oriented machine learning system for bank marketing

propensity prediction.



\## Planned Pipeline



Data Ingestion → Data Validation → EDA → Feature Engineering →

Model Training → Model Evaluation → API → Docker → CI/CD → Deployment



\## Technologies



\- Python

\- Pandas

\- NumPy

\- Scikit-learn

\- XGBoost

\- LightGBM

\- CatBoost

\- FastAPI

\- Docker

\- GitHub Actions
